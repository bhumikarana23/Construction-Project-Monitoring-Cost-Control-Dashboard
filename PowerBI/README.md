# Power BI – Construction Project Monitoring Dashboard

## Overview

This folder is dedicated to the Power BI dashboard developed for monitoring construction project performance.

The dashboard is designed to transform structured construction datasets into interactive visual reports, enabling consolidated monitoring of project progress, cost performance, resource utilisation and operational risks.

## Dashboard Modules

### 1. Executive Project Overview
- Total project budget.
- Planned versus actual progress.
- Overall project performance indicators.
- Earned Value Management summary.

### 2. Schedule & Progress Monitoring
- Monthly progress trends.
- Activity completion status.
- Planned versus actual timelines.
- Schedule deviation monitoring.

### 3. Cost Control & BOQ Analysis
- Budget versus actual expenditure.
- Earned Value metrics.
- BOQ quantity and cost variations.
- Cost performance monitoring.

### 4. Material Management
- Material receipts and consumption.
- Stock availability.
- Planned versus actual consumption.
- Material variance analysis.

### 5. Labour & Resource Monitoring
- Planned versus actual workforce.
- Trade-wise labour deployment.
- Workforce variance.
- Resource utilisation indicators.

### 6. Project Risk Register
- Risk categorisation.
- Probability and impact assessment.
- High-priority risk identification.
- Mitigation tracking.

## Key Performance Indicators

The dashboard incorporates the following metrics:

- Planned Value (PV)
- Earned Value (EV)
- Actual Cost (AC)
- Cost Variance (CV)
- Schedule Variance (SV)
- Schedule Performance Index (SPI)
- Cost Performance Index (CPI)
- Progress Variance

The objective is to demonstrate the application of business intelligence and data visualisation techniques to construction project monitoring and project controls.
