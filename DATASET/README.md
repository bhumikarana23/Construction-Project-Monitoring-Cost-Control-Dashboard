# Dataset – Construction Project Monitoring & Cost Control

## Overview

This folder contains the structured datasets used to develop the Construction Project Monitoring & Cost Control Dashboard.

The datasets represent a hypothetical high-rise residential construction project and cover various aspects of construction planning, progress monitoring, cost control and resource management.

All datasets are synthetic and created exclusively for portfolio demonstration.

## Project Scenario

| Parameter | Details |
|---|---|
| Project Type | High-Rise Residential Development |
| Location | Gurugram, Haryana |
| Towers | 3 |
| Floors per Tower | 25 |
| Indicative Budget | ₹150 Crore |
| Project Duration | January 2026 – December 2027 |
| Reporting Date | 23 November 2026 |

## Dataset Description

| Dataset | Description |
|---|---|
| Monthly_Progress.csv | Monthly planned and actual construction progress |
| Activity_Tracker.csv | Construction activity schedules, status and progress |
| BOQ_Tracker.csv | Bill of Quantities, planned quantities and cost tracking |
| Material_Tracker.csv | Material receipts, consumption and stock monitoring |
| Labour_Tracker.csv | Planned and actual labour deployment |
| Risk_Register.csv | Project risks, impact, probability and mitigation measures |
| Project_Master.csv | Project-level information and reference details |

## Data Applications

The datasets support:

- Planned versus actual progress analysis.
- Activity-level schedule monitoring.
- Budget and cost performance evaluation.
- BOQ quantity and cost variance analysis.
- Material consumption and inventory monitoring.
- Labour deployment and productivity tracking.
- Project risk identification and monitoring.

## Data Preparation

The datasets were organised into structured CSV files for integration with Microsoft Power BI.

Data preparation included organising fields, standardising records and preparing relevant calculated values for dashboard analysis.

## Usage

These datasets serve as the primary data source for the Excel monitoring workbook and Power BI dashboard.

**Disclaimer:** All project details, quantities, costs and operational records are illustrative. They do not represent actual DLF, Godrej or any other company's project data.
