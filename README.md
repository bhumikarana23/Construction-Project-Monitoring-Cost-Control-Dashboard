# Construction Project Monitoring & Cost Control Dashboard

<badge>Portfolio Project</badge>

## 1. Project Overview

This project focuses on developing an integrated construction project monitoring and cost control framework for a hypothetical high-rise residential development in Gurugram, Haryana.

The dashboard is designed to monitor construction progress, project expenditure, budget utilisation, BOQ quantities, material consumption, labour deployment and project risks through structured data analysis and visual reporting.

The project demonstrates the application of project controls, construction planning and performance monitoring techniques using Microsoft Excel and Power BI.

**Project Type:** Independent Portfolio Project  
**Project Domain:** Construction Operations | Project Planning | Project Controls  
**Tools:** Microsoft Excel | Power BI | DAX

## 2. Project Scenario

The dashboard is based on an illustrative residential construction project with the following characteristics:

| Parameter | Details |
|---|---|
| Project Type | High-Rise Residential Development |
| Location | Gurugram, Haryana |
| Number of Towers | 3 |
| Floors per Tower | 25 |
| Indicative Project Budget | ₹150 Crore |
| Baseline Duration | January 2026 – December 2027 |
| Reporting Date | 23 November 2026 |

*All project details and datasets are hypothetical and created solely for portfolio demonstration. They do not represent an actual DLF or Godrej project.*

## 3. Project Objectives

- Monitor planned versus actual construction progress.
- Track project expenditure against the approved illustrative budget.
- Evaluate schedule and cost performance using Earned Value Management (EVM).
- Monitor BOQ quantities and cost variations.
- Track material consumption and inventory levels.
- Analyse labour deployment and resource utilisation.
- Identify project risks and potential execution challenges.

## 4. Dashboard Modules

### 1. Executive Project Overview
Consolidated view of project performance through key metrics, progress indicators and cost summaries.

### 2. Schedule & Progress Monitoring
Tracks planned versus actual progress, activity status, completion percentages and schedule deviations.

### 3. Cost Control & BOQ Analysis
Monitors budget utilisation, actual expenditure, earned value and BOQ quantity and cost variations.

### 4. Material Management
Tracks material receipts, consumption, stock availability and consumption variances.

### 5. Labour & Resource Monitoring
Analyses planned versus actual workforce deployment and resource utilisation.

### 6. Project Risk Register
Organises project risks according to their likelihood, impact, priority and mitigation requirements.

## 5. Key Performance Indicators

The project incorporates the following project control metrics:

| KPI | Purpose |
|---|---|
| Planned Progress | Measures scheduled project progress |
| Actual Progress | Measures reported project progress |
| Progress Variance | Compares planned and actual progress |
| Planned Value (PV) | Budgeted value of scheduled work |
| Earned Value (EV) | Budgeted value of completed work |
| Actual Cost (AC) | Cost incurred for completed work |
| Cost Variance (CV) | Evaluates cost performance |
| Schedule Performance Index (SPI) | Evaluates schedule efficiency |
| Cost Performance Index (CPI) | Evaluates cost efficiency |

## 6. Tools & Technologies
