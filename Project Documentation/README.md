# Project Documentation

## Overview

This folder contains supporting documentation explaining the methodology, data structure and performance indicators used in the Construction Project Monitoring & Cost Control Dashboard.

The documentation provides context for understanding the project framework, analytical approach and calculations used throughout the monitoring process.

## Documentation Contents

### 1. Project Methodology

Explains the overall approach followed in developing the project, including:

- Project scenario and assumptions.
- Dataset organisation.
- Construction monitoring framework.
- Schedule and cost control methodology.
- Dashboard development approach.
- Project performance evaluation.

### 2. KPI Definitions

Documents the key performance indicators used in the dashboard, including:

- Planned Progress.
- Actual Progress.
- Progress Variance.
- Planned Value (PV).
- Earned Value (EV).
- Actual Cost (AC).
- Cost Variance (CV).
- Schedule Variance (SV).
- Schedule Performance Index (SPI).
- Cost Performance Index (CPI).

### 3. Analytical Framework

The project uses construction project controls concepts and Earned Value Management to evaluate progress and cost performance.

The documentation also explains the use of BOQ monitoring, material tracking, labour deployment and risk assessment.

## Purpose

This documentation is intended to make the project methodology transparent, explain the underlying calculations and provide a reference for interpreting the dashboard.

**Note:** All methodology and examples relate to an illustrative portfolio case study, not an actual construction project.
