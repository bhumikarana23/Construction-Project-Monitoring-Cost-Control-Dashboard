# Excel – Construction Project Monitoring & Cost Control

## Overview

This folder contains the Excel-based construction project monitoring and cost control workbook developed as part of the portfolio project.

The workbook provides a structured framework for tracking construction progress, activity schedules, project costs, BOQ quantities, material consumption, labour deployment and project risks.

## Key Components

### 1. Project Dashboard
- Consolidated project performance indicators.
- Planned versus actual progress.
- Earned Value Management metrics.
- Visual summaries of schedule and cost performance.

### 2. Monthly Progress Monitoring
- Monthly planned progress.
- Monthly actual progress.
- Cumulative progress comparison.
- Identification of progress deviations.

### 3. Activity Tracker
- Construction activity schedules.
- Planned and actual dates.
- Activity completion status.
- Progress and cost tracking.

### 4. BOQ Tracker
- Item-wise quantity monitoring.
- Planned versus actual quantities.
- Unit rates and cost calculations.
- Quantity and cost variance analysis.

### 5. Material Tracker
- Opening stock and material receipts.
- Material consumption.
- Closing stock calculations.
- Material availability monitoring.

### 6. Labour Tracker
- Planned and actual workforce.
- Trade-wise labour deployment.
- Workforce variance.
- Productivity monitoring.

### 7. Risk Register
- Risk identification.
- Probability and impact assessment.
- Risk prioritisation.
- Mitigation measures.

## Software Used

- Microsoft Excel
- Excel formulas and functions
- Pivot tables and charts
- Conditional formatting

## Purpose

The workbook demonstrates how spreadsheet-based tools can be used to organise construction project information and support systematic monitoring of project performance.

**Note:** The workbook is based on synthetic project data created for portfolio demonstration.
